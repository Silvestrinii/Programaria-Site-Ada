# 💻 Ada Lovelace - Website

Este projeto é um site desenvolvido durante um curso de programação com o objetivo de aprender os fundamentos da criação de páginas web.  
A página apresenta informações sobre **Ada Lovelace**, matemática inglesa considerada a primeira programadora da história!!

## 📚 Sobre o projeto

O site foi criado como exercício prático durante um curso de programação para aprender:

- Estrutura de páginas web  
- Estilização de interfaces  
- Organização de arquivos em um projeto  
- Boas práticas iniciais de desenvolvimento

O conteúdo do site apresenta um breve resumo da vida de Ada Lovelace, suas contribuições para a computação e sua importância histórica para a tecnologia.

## 🚀 Tecnologias utilizadas

- **HTML** → estrutura da página  
- **CSS** → estilização e layout  
- **Java** → lógica e funcionalidades

## 🎯 Objetivo do projeto

Este projeto teve como objetivo:

- Praticar desenvolvimento web básico

- Criar um projeto simples durante um curso de programação
